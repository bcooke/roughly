# Establish a topic graph proposal

Review an implemented topic/relationship pattern and define a Roughly-specific model that supports overlapping concepts without collapsing exact question instruments or response evidence.

- [Topic Graph](../../Topic%20Graph.md) distinguishes membership, semantic relations, and statistical association.
- [The model proposal](../../discovery/2026-11-02-topic-graph-model.md) describes identities, event-sourced curation, provenance, relational projections, and a migration from the category field.
