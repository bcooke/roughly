# Glossary

| Term | Meaning |
| --- | --- |
| Question | A defined prompt with response options and an interpretation context. |
| Response | A principal’s recorded answer to an exact instrument, with collection context. |
| Principal | An identity supporting continuity and authority; not proof of one human, a legal identity, or an authenticated account. |
| Instrument | An exact question definition, including wording, language, format, and option identities. |
| Answer option | An identified choice whose label and meaning belong to an instrument. |
| Sample | The people or responses actually included in an analysis. |
| Target population | The group a study seeks to describe; it is not interchangeable with its respondents. |
| Slice | A filtered subset of an analysis, subject to privacy and interpretation constraints. |
| Demographic | An attribute used to describe or group participants; it can be elicited through a question. |
| Sample size | The number of eligible observations; a larger count alone does not establish representativeness. |
| Factoid | A derived statement that needs the sample, question, and limitations attached to it. |
| Methodology | How questions, participation, sampling, analysis, and reporting produce a result. |

See [Polling Methodology](Polling%20Methodology.md) for interpretation and [Participant Identity](Participant%20Identity.md) for the distinct meanings of identity and anonymity. Technical terms are explained in [Domain Writes](Domain%20Writes.md) and [Read Models](Read%20Models.md).

[Question Instruments](Question%20Instruments.md) separates answer formats from result presentation; [Collection Context](Collection%20Context.md) distinguishes conditions and their provenance.
